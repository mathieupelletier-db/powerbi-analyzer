# Examples

These reports are regenerated from `tests/fixtures/pbix/small_bad.pbip/` whenever the
fixture changes. They are checked in so reviewers can preview the report shape without
running the tool.

To regenerate:

```bash
pba pbix tests/fixtures/pbix/small_bad.pbip --out examples/sample-report.md
pba pbix tests/fixtures/pbix/small_bad.pbip --out examples/sample-report.html
```
